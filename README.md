# NUTRI-TUKOY
A Community Nutrition Hotspot Detection and Intervention Prioritization System

Group 14 · OOP 101 · Batangas State University – CICS

## Goal
Turn individual child nutrition records into community-level information so health
workers can see which puroks need nutrition programs first. The system prioritizes
and refers. It never diagnoses or prescribes.

## Tech
- Java (OOP core)
- Python (trend forecast)

## Status
Work in progress. Built step by step.
